| Version | Status |
|---------|--------|
| `main` (latest) | Active development |

Only published releases receive security updates. There are no LTS versions.

## Reporting Bugs

Before filing an issue:
1. Search existing issues
2. Run `go test ./...` to verify it's not a known flaky test
3. Include: OS, Go version, Gash version/commit, minimal repro command

## Feature Requests

Open a GitHub Issue with the "enhancement" label. Include:
- Problem statement
- Proposed solution
- Alternatives considered
- Willingness to implement

## Security Vulnerabilities

**Do NOT open public issues.** Use [GitHub Security Advisories](https://github.com/Xmar1881/Gash/security/advisories/new) for private disclosure.
